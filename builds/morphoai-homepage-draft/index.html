Start a design project See how it works

From requirements to a design you can build

  1. Generate

    Give it your parts and what the machine has to do. It produces hundreds of design candidates that already pass basic checks, and you choose which ones to pursue.

  2. Simulate

    Each design runs through a full physics simulation with a controller tuned for it, so you see how it actually moves before you machine anything.

  3. Optimize

    Refine the winner for cost, weight, performance, and how easy it is to manufacture, with every trade-off visible.
