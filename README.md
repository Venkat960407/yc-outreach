# YC Outreach

Cold outreach to small YC startups, mostly robotics and hardware, plus a few Seattle-area companies.

## Layout

- `tracker.xlsx`: every company, its status, and follow-up dates (also kept in Documents/YC Outreach on Venkat's PC)
- `companies/`: one file per company with research notes, the email draft, and the follow-up
- `builds/`: small projects made for Tier A companies, one folder each
- `data/batchN.py`: raw research for each batch
- `scripts/build.py`: regenerates `companies/` and `tracker.xlsx` from `data/`

## Tiers

- **A:** something built for them (link in the email)
- **B:** strong, specific observation or a direct reason to reply (intern posting, local, etc.)
- **C:** lighter fit or weaker hook

## Before sending any email

1. Open the company's site and confirm the observation is still true.
2. Check the email address if it's marked "guess" (Hunter.io or Apollo).
3. For Tier A, read the build's README so you can talk about it.
4. Update Status and Date sent in the tracker.

## Pace

About 20 emails a day on weekdays from Gmail. Follow up once, 5 to 7 days later, in the same thread.
